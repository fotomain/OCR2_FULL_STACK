2. Three-Tier Architectural Core Breakdown

Exhaustive component profiles for Stage 1 FastAPI, Stage 2 Django, and Stage 3 Expo Mobile

STAGE 1 • CORE BACKEND Port 8000

stage1_ml_ocr (Python FastAPI)

High-throughput machine learning inference, hybrid OCR fallback, and multi-tenant corpus training engine.

  • Execution Engine: FastAPI + Uvicorn ASGI server with hot-reload support.
  • Hybrid OCR Stack: PyPDF & PDFPlumber (direct vector text extraction) with automatic Tesseract OCR fallback for scanned images.
  • ML Training Pipeline: Scikit-learn Pipeline combining TF-IDF N-gram vectorizer with balanced Logistic Regression classifier.
  • Corpus Ingestion: Ingests Input 1 (./dataset_for_ml/) + Input 2 (./dataset_for_ml/+user_email).
  • Model Persistence: Dumps model.joblib, vectorizer.joblib, label_encoder.joblib, and metrics.json into ./output/model/.
  • Entity & Requisite Parser: Extracts Tax ID (INN), invoice numbers, dates, currency amounts, and tabular line items.
Location: ./stage1_ml_ocr/ • Runner: ./run_stage1_ml_ocr
STAGE 2 • WEB DASHBOARD Port 8080

stage2_frontend_web (Python Django 5.x)

Corporate executive web dashboard providing verified single-file document upload, anti-bot validation, and instant JSON exports.

  • Google OAuth 2.0: Native authentication with pre-configured Client ID & Refresh token.
  • StartLearnModelButton: Triggers asynchronous background model retraining with animated progress spinner and KPI readouts.
  • SelectDocumentButton: Drag-and-drop file uploader enforcing strictly one file (PDF, PNG, JPG, TIFF).
  • Local Anti-Bot CAPTCHA: Dynamic mathematical arithmetic puzzle ensuring verified human submission.
  • RecognizeDocumentButton: Conditional lock ensuring button activates only after file selection + CAPTCHA resolution.
  • Auto-Download JSON: Instant client-side Blob generation automatically saving recognition_result_*.json.
Location: ./stage2_frontend_web/ • Runner: ./run_stage2_frontend_web
STAGE 3 • MOBILE & WEB Port 8081

stage3_frontend_mobile (React Native Expo MD3)

Cross-platform mobile and web client featuring Material Design 3, Redux-Saga async architecture, and Expo SQLite storage.

  • UI Design System: React Native Paper Material Design 3 (MD3) with curated slate/indigo typography.
  • Redux State Machine: Redux Toolkit (authSlice, ocrSlice, historySlice) coupled with Redux-Saga side-effect orchestration.
  • Expo SQLite Multi-Tenant DB: Persistent relational tables (users, scans) providing multi-persona account switching.
  • Live Camera Snap: Instant document photo capture automatically bound to the recognition queue.
  • Full Feature Parity: Same StartLearnModelButton, SelectDocumentButton, CAPTCHA puzzle, and auto-download engine.
  • Expo Router: File-based cross-platform navigation for iOS, Android, and Web preview.
Location: ./stage3_frontend_mobile/ • Runner: ./run_stage3_frontend_mobile

4. Security, Google OAuth & Anti-Bot Architecture

Double-layer authentication: Google OAuth 2.0 corporate credentials + dynamic local mathematical CAPTCHA

Google OAuth 2.0 Security Configuration

GOOGLE_CLIENT_ID=your-google-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-google-client-secret
GOOGLE_REFRESH_TOKEN=your-google-refresh-token

Google OAuth 2.0 Handshake

  • Web Flow: Django redirects to Google authorization consent; upon callback, exchanges authorization code for refresh/access tokens.
  • Mobile Flow: Expo AuthSession initiates secure native browser authentication and parses authorization response.
  • Session Management: Tokens securely cached; user profiles synced to SQLite users table.

Local Anti-Bot CAPTCHA Protection

  • Dynamic Math Puzzle: Generates randomized arithmetic equations (e.g. 14 + 7 = ?) per session.
  • Conditional UI Locking: RecognizeDocumentButton remains strictly disabled until the math challenge is solved.
  • Zero External Reliance: Operates entirely client/session side with zero third-party tracking or latency.

5. Comprehensive API & Route Directory

Specification of RESTful interfaces across the Stage 1 FastAPI engine and Stage 2 Django backend

Tier Method Endpoint Parameters / Request Body Response Description
Stage 1 POST /api/v1/ocr/recognize file (UploadFile), user_email (str), save_to_dataset (bool) Returns structured RecognitionResponse JSON with requisites, line items, and confidence.
Stage 1 POST /api/v1/model/train None (Triggers scan over ./dataset_for_ml/) Asynchronously retrains model on all tenant data and updates serialized weights.
Stage 1 GET /api/v1/model/status None Returns current model status, version (v2.1.0), training timestamp, and accuracy metrics.
Stage 1 POST /api/v1/dataset/upload file (UploadFile), user_email (Form str) Saves contribution directly into isolated directory ./dataset_for_ml/+user_email.
Stage 1 GET /api/v1/dataset/stats None Returns detailed file counts across base corpus and individual user partitions.
Stage 1 GET /health None Returns {"status": "healthy"} probe for orchestration liveness checks.
Stage 2 GET / Session Cookie Renders executive Django web dashboard with upload forms and live KPI components.
Stage 2 POST /recognize-proxy/ document (File), captcha_answer (str) Verifies CAPTCHA and proxies recognition request to Stage 1 FastAPI backend.
Stage 3 GET / Web Browser / Metro Serves React Native Expo web bundle on port 8081 with MD3 theme and SQLite store.
