OCR2 Multi-Tenant Document Recognition Architecture

A unified, three-tier intelligent document extraction ecosystem engineered with Python FastAPI, Scikit-Learn OCR ML, Django Web Dashboard, and React Native Expo MD3 Mobile Client. Built for enterprise invoice, medical record, and tax document parsing with multi-tenant data isolation.

Stage 1: FastAPI (Port 8000)
Stage 2 Web: Django (Port 8080)
Stage 2 Mobile: Expo Router MD3 (Port 8081)
Google OAuth 2.0 + Local CAPTCHA
Expo SQLite Multi-Tenant Database

1. System Topology & Component Overview

Decoupled microservice architecture with dual client frontends

STAGE 1

stage1_ml_ocr (FastAPI)

Core Machine Learning & Multi-Tier OCR Engine

  • Input 1: ./dataset_for_ml/ (Base Corpus)
  • Input 2: ./dataset_for_ml/+user_email (Multi-tenant user subfolders)
  • Output: ./output/model/ (Trained ML artifacts)
  • OCR Engine: Tesseract, PyPDF, PDFPlumber, PIL
  • ML Classifier: TF-IDF N-gram + Logistic Regression
  • Endpoints: /recognize, /train, /status, /upload
Port 8000 • OpenAPI 3.0
STAGE 2 WEB

stage2_frontend_web (Django)

Executive Corporate Web Application

  • Google OAuth 2.0: Client ID & Refresh token integration
  • StartLearnModelButton: Real-time ML training trigger
  • SelectDocumentButton: Single-file PDF/Image picker
  • Local CAPTCHA: Dynamic anti-bot math puzzle
  • RecognizeDdocumentButton: Strict conditional lock
  • Auto-Download: Automatic JSON file saving
Port 8080 • Django 5.x
STAGE 2 MOBILE

stage2_frontend_mobile (Expo)

React Native Mobile & Web Application

  • UI Framework: React Native Paper MD3 Theme
  • State Management: Redux Toolkit + Redux Saga
  • Multi-User DB: Expo SQLite persistent storage
  • Camera OCR: Live photo capture & auto-attach
  • Auth: Google Auth Session & persona switcher
  • Full Parity: Same buttons, CAPTCHA & auto-download
Port 8081 / 3000 • Expo Router

3. Stage 1: ML OCR FastAPI Backend Specification

Technical details of dataset ingestion, OCR processing, and machine learning models

Method Endpoint Description Inputs / Parameters Output Schema
POST /api/v1/ocr/recognize Recognizes single PDF/Image file using OCR & ML models file (UploadFile), user_email (str), save_to_dataset (bool) RecognitionResponse (JSON)
POST /api/v1/model/train Triggers training over Input1 + Input2 and updates ./output/model/ None (processes all data in ./dataset_for_ml/) TrainResponse (JSON)
GET /api/v1/model/status Returns model status, version, accuracy, and dataset metrics None ModelStatusResponse (JSON)
POST /api/v1/dataset/upload Ingests user training file into ./dataset_for_ml/+user_email file (UploadFile), user_email (Form string) DatasetUploadResponse (JSON)
GET /api/v1/dataset/stats Returns statistics across base dataset and all user folders None DatasetStatsResponse (JSON)

4. Stage 2: Django Web Frontend Architecture

Business-oriented interface with single-file validation, CAPTCHA, and auto-download

Buttons & Functional Components

  • StartLearnModelButton: Dispatches async model training to Stage 1, displays live progress spinner and accuracy KPIs.
  • SelectDocumentButton: Drag-and-drop file picker enforcing strictly one file (PDF, PNG, JPG, TIFF).
  • Small Local CAPTCHA: Dynamic mathematical/puzzle anti-bot check that must be solved before recognition unlocks.
  • RecognizeDdocumentButton: Disabled by default; unlocks ONLY when 1 file is selected AND CAPTCHA is solved.
  • Auto-Download: Automatically creates a client Blob and triggers browser file download of recognition_result_*.json.

Executive UI Design System

  • Color Tokens: Curated corporate light palette (#f8fafc, #ffffff, #4f46e5, #0284c7, #059669).
  • Typography: Google Fonts Inter (body) and Outfit (headings) for an ultra-premium look.
  • Micro-Animations: Glowing pulses, smooth progress transitions, crisp card shadows.
  • Structured Tabs: Requisites Grid, Line Items DataTable, Raw JSON Viewer, OCR Text Viewer.

5. Stage 2: React Native Expo Mobile App Architecture

Redux-Saga state machine, Expo-SQLite multi-user store, and Material Design 3

Redux & Saga Architecture

  • Redux Toolkit Slices: authSlice (users/tokens), ocrSlice (file selection, CAPTCHA, training), historySlice (audit scans).
  • Redux Saga Middleware: Handles asynchronous side effects for model training (handleStartLearnModel) and document recognition upload (handleRecognizeDocument).
  • Vision Camera Capture: Takes live document snapshots and automatically attaches them to the SelectDocumentButton flow.

Expo SQLite Multi-User Storage

  • users Table: Stores multi-tenant accounts (id, email, name, role, auth_provider, created_at).
  • scans Table: Stores historical OCR runs (id, user_email, filename, document_type, confidence, total_amount, raw_json).
  • Account Switcher: Instant switching between corporate personas with data isolation.

7. Operations & Quick Start Guide

One-click execution commands to launch and test the entire system

# 1. Launch all 3 services concurrently with one command:
./start_all.sh

# 2. Or launch individual applications:
./stage1_ml_ocr/run.sh # FastAPI Backend (http://127.0.0.1:8000)
./stage2_frontend_web/run.sh # Django Web App (http://127.0.0.1:8080)
./stage2_frontend_mobile/run.sh # Expo Mobile App (http://127.0.0.1:8081)

# 3. Run automated verification test suites:
PYTHONPATH=. .venv/bin/pytest stage1_ml_ocr/tests/ -v
PYTHONPATH=stage2_frontend_web .venv/bin/python stage2_frontend_web/manage.py test ocr_web
